# Vibe Spec context
<!-- vibe-spec: literal-file -->

This repository keeps durable project knowledge. For a direct spec discovery,
query, authoring or validation request, use the standalone `spec` skill. Discover
the root with `vibe-spec root` and read only the relevant plan and lessons.
Without the binary, inspect an existing `docs/spec/` or `.spec/` read-only and
report validation unavailable. Do not create a root simply to answer a question.

Toolkit orientation belongs to `vibe`; lifecycle work belongs to `flow` when
installed. When Flow requests a bounded Spec artifact operation, perform it and
return to Flow. A delegated worker follows its brief without restarting routers.
Do not install absent components or change host configuration without a request.
