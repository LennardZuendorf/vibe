# Spec

This directory is the project's spec root: the persistent record of what the product is, how it is built and why.

- [product.md](product.md): what the product is for and who uses it.
- [tech.md](tech.md): architecture and technical constraints.
- [design.md](design.md): design principles and interface rules.
- [plan.md](plan.md): current direction and open decisions.
- [lessons.md](lessons.md): rules learned from failures.
