# AGENTS.md: spec root

Scoped guide for work inside this directory. The repository's root guide applies first.

- Invoke the `spec` skill before editing any file here.
- Keep each hub at 80 lines or fewer; move detail into a note under a kind folder (`areas/`, `flows/`, `concepts/`, `platform/`, `tech/`, `decisions/`, `questions/`).
- Link every new note from a hub or its folder `README.md`.
- Set `updated:` to today's date when you change a file.
- Run `vibe-spec validate --strict` before you finish.
