## Deliverable
`vibe-flow state set <flow.phase> [feature] [--confirm]`: target must exist, must be in current `next` (`idle` always legal), gated edges (`feature.plan>feature.impl`, `feature.verify>feature.compound`) require `--confirm`; refusal exits 1 listing legal next or naming the gate. No `--force` — repair is `idle` then walk forward. Every write appends a ledger event. `/flow` becomes a thin wrapper (`confirm` token → `--confirm`); hooks and the TUI (F10) call the same `check_transition` function — one enforcement point, not several that can disagree.
