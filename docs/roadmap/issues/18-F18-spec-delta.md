## Deliverable
Header-keyed delta/promotion engine: `## ADDED|MODIFIED|REMOVED Requirements` blocks, `### Requirement: <ID> — <name>` (SHALL/MUST), `#### Scenario:` GIVEN/WHEN/THEN — MODIFIED replaces the full requirement text in place, REMOVED carries a "why" line. Ports `check-drift.sh`. `vibe-spec export --openspec <dir>` / `import --openspec <dir> [--feature <name>]`: lossless round-trip for requirements/scenarios/deltas/tasks; documented-lossy for `updated:` dates, branch docs, lessons, drift state. Adopts OpenSpec's grammar verbatim; does not adopt its `openspec/` root or capability-per-folder layout.

## Scope
**Owns:** the delta engine, `check-drift` port, OpenSpec import/export.
**Does not own:** the OpenSpec CLI or its layout (explicitly rejected); the underlying validators the delta engine relies on (F17, already landed); the migration to `docs/spec/` (F20).
