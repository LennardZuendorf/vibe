## Deliverable
Payload reader for `.vibe/run/inject/<provider>.json`. Per-session ledger `.vibe/run/instruct/sessions/<id>.json` `{provider:{seq,event_ids}}`: `level` injected every turn; `edge` injected when `seq` advanced since the ledger (so a fresh or resumed session with no ledger gets orders on turn one, never waits for a second turn); unseen `events` injected once each, then marked. Command providers from `.vibe/providers/<id>.json` manifests (repo or global tier only, never from fetched sources): timeout 500 ms default / 1500 ms total wall cap, dedupe, truncation to budget. Recompose triggers a spec-drift event when applicable.
